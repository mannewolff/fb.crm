# fb.crm
Ein CRM für Freiberufler

fb.crm ist ein self-hostbares Mini-CRM für eine Person: Kunden mit Ansprechpartnern, Angebote mit
Positionen und Rechnungen gegen diese Angebote, bis zum fertigen Rechnungsdokument.

## Dokumentation

Die Dokumentation liegt in zwei Teilen unter `docs/`:

- [`docs/betrieb.md`](docs/betrieb.md) — Einrichten und Betreiben: Voraussetzungen, Konfiguration,
  Start, Einrichtung des Kontos, Betrieb unter eigenem Namen, Mailversand und vergessenes Passwort.
- [`docs/bedienung.md`](docs/bedienung.md) — Bedienung: der Weg von der Firma über das Angebot bis
  zur Rechnung, dazu eigene Angaben, Rechnungseinstellungen und die übrigen Bereiche.

Vor der Einrichtung liest man hier im Projekt, beginnend mit dem Teil „Betrieb". Sobald fb.crm
läuft, steht dieselbe Dokumentation in fb.crm unter „Dokumentation".
